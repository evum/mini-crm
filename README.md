# miniCRM

Приложение для управления строительными объектами и задачами. Постановщик
создаёт объекты и задачи, назначает исполнителей и принимает работы.
Исполнитель видит свои задачи, берёт их в работу и отправляет на проверку.
Изменения статусов сохраняются в истории.

Стек: React, TypeScript, Vite, Tailwind CSS, shadcn/ui и TanStack Query.
Авторизация и база данных — Supabase; права доступа защищены RLS.

## Запуск

Требуются Node.js, npm и проект Supabase.

1. Подготовьте базу и пользователей по [инструкции установки миграции](supabase/README.md#применение).
2. Установите зависимости: `npm ci`.
3. Скопируйте `.env.example` в `.env.local` и заполните:

   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your-key
   ```

   Используйте публичный publishable key. Секретные ключи во фронтенд не добавляйте.
4. Выполните `npm run dev` и откройте адрес из терминала.
5. Войдите под пользователем, подготовленным в Supabase согласно инструкции.

Сборка с проверкой TypeScript: `npm run build` (результат в `dist`).
Предпросмотр сборки: `npm run preview`.

Подробности установки базы, настройки Auth и пользователей:
[База данных miniCRM](supabase/README.md).
