# mini-crm

Мини CRM.

## Фронтенд

React + TypeScript + Vite, Tailwind CSS и shadcn/ui. Запросы и состояние
авторизации управляются через TanStack Query (`QueryClientProvider`, `useQuery`,
`useMutation`). Экран входа использует Supabase Auth (email и пароль),
восстанавливает сессию после перезагрузки и позволяет выйти из аккаунта.
После входа показывается заглушка «Мои задачи»; список задач пока не реализован.
Регистрации в интерфейсе нет. Открытую регистрацию нужно отключить отдельно
в настройках Supabase Auth.

### Запуск

1. Выполните `npm install`.
2. Скопируйте `.env.example` в `.env.local` и укажите URL проекта и
   **publishable key** из Supabase. Если `.env.local` уже настроен, сохраните его.
3. Выполните `npm run dev` и откройте адрес из терминала.

Переменные `VITE_*` доступны браузеру: не помещайте туда secret key,
`service_role`, пароль базы или другие секреты. Файлы `.env.local` исключены из Git.
Изменение переменных окружения требует перезапуска dev-сервера.

Проверка типов и production-сборка: `npm run build`. Результат — каталог `dist`.
Предпросмотр сборки: `npm run preview`.

Экран входа и используемые им компоненты shadcn/ui находятся в
`src/components/login`, заглушка «Мои задачи» — в `src/components/my-tasks`.
`src/App.tsx` проверяет сессию и выбирает экран. Настройки shadcn/ui — в
`components.json`. Тема и Tailwind подключены в `src/styles.css`,
алиас `@/` указывает на `src/`. Добавление компонентов:
`npx shadcn@latest add <component>`.

Сессия синхронизируется с событиями Supabase Auth. При выходе или смене
пользователя кэш прикладных запросов очищается. Автоматические повторы
запросов входа отключены. Пароли и кэш запросов не сохраняются отдельно на диск;
сохранением сессии управляет Supabase Auth.

Для проверки входа используйте пользователя, вручную созданного в Supabase Auth.
